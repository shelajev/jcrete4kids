# Run the Starter

The workspace starts in `/home/coder/project`.

The project already has:

- `Main.java`: a tiny Java web server
- `web/game.js`: the game code
- `web/style.css`: the game style
- `web/index.html`: the browser page

In the terminal, run:

```bash no-run-button
cd /home/coder/project
java -version
javac Main.java
java Main
```

Open the **Game Preview** tab. You should see a simple starter with a yellow circle.

## Open Codex

Open the Codex panel in VS Code.

Sign in or enter the key from your instructor.

If Codex asks whether you trust the folder, trust it for this workshop.

## First Prompt

Copy this into Codex:

```text no-run-button
Look at this project. It is a Java server with a browser game in web/game.js. Explain the files in three short bullets, then wait for my next request.
```

When Codex answers, you are ready to start designing.
