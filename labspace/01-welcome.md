# Let's Make Games with Codex

Today you are the game designer. Codex is your coding partner.

You will:

- run a tiny starter game
- ask Codex for a 3D-style cat game
- ask Codex for a 2D fish game
- add enemies, score, health, levels, and sprites
- use your own image as a game asset

The original workshop is **"English Codex Workshop"**: **Let's Make 3D Games with Codex!**

## How This Works

The original workshop set up VS Code, Java, and Codex on each student's computer. This Labspace already has that setup.

Java runs a tiny local web server. JavaScript draws the game in the browser, so everyone can use the **Game Preview** tab.

Open the IDE tab and keep these instructions visible while you work.

## The Labspace Rule

Do not make desktop games with Swing, JavaFX, LWJGL, or native OpenGL windows. Those windows do not open from this container.

Keep the game in the browser.

Good phrases for Codex:

```text no-run-button

port 3000

```
