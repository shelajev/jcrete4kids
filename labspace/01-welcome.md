# Let's Make Browser Games with Codex

In this lab, you will use Codex inside VS Code to turn a tiny starter into your own browser game.

You will:

- run the starter game
- sign in to Codex
- ask Codex to change the game
- add enemies, sprites, score, health, and new rules

The original workshop is **"English Codex Workshop"**: **Let's Make 3D Games with Codex!**

## How This Works

The Canva slides used each student's own computer. This Labspace already has the tools and the starter files.

Java runs a tiny local web server. JavaScript draws the game in the browser, so everyone can use the **Game Preview** tab.

Open the IDE tab and keep these instructions visible while you work.

## One Rule

Do not make desktop games with Swing, JavaFX, LWJGL, or native OpenGL windows. Those windows do not open from this container.

Keep the game in the browser.
